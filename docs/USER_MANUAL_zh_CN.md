# MaxFastBuild 用户手册

![MaxFastBuild 图标](assets/maxfastbuild-icon.svg)

面向玩家的使用说明。服务端配置、权限与运维请另见管理员文档。

## 需要什么

- Minecraft Java 版 **26.2**
- **Fabric Loader** 与 **Fabric API**（与 26.2 匹配的版本）
- 服务器已安装并启用 **MaxFastBuild**（玩家侧只需客户端 Mod）

## 安装客户端

将客户端 jar 与 Fabric API 放入同一游戏实例的 `mods` 目录，启动游戏后加入支持本模组的服务器。

## 径向菜单

1. **按住**快捷键（默认 **左 Alt**，可在「选项 → 控制 → MaxFastBuild」改绑）打开菜单；**松开即关闭**。
2. 鼠标移到扇区高亮，**松开键**或**左键点击**选中模式。
3. 菜单背景透明，可看到身后世界。

## 放置与破坏

| 主手 | 行为 |
|------|------|
| 可放置的方块 | **放置**模式 |
| 镐 / 斧 / 铲 / 锄 / 剑 / 剪刀 | **破坏**模式（须能有效破坏目标；例如黑曜石需要合适镐） |
| 空手、弓、以及其他物品 | **无模式** |

### 选区操作

1. 从径向菜单选择形状（直线、墙、立方体等）。
2. **右键**确认第一个点，再 **右键**确认第二个点并提交。
3. **左键**取消当前选区。
4. 准星可对空气选点（浮空角点）；打到方块时，放置使用原版规则（可替换块用该格，否则相邻面）。
5. **Shift + 滚轮**调节视线延伸 **1～64** 格；普通滚轮仍切换物品栏。
6. 半透明预览只显示形状**外壳**与外框，避免大体积选区挡住视线。

### 费用与材料（由服务器决定）

- **放置**：生存模式下会从背包扣除对应方块；若服务器开启经济，会按规则扣费。材料或余额不足时会拒绝任务并提示。
- **附近容器取料**（生存粘贴）：开启 `inventory.search-containers`（默认开启）时，除背包外还会在脚边 **5 格半径**（`container-search-radius`）内搜索箱子（含大箱子）、陷阱箱、木桶、已放置的潜影盒，以及这些容器内的潜影盒，一起凑齐材料；消耗与退还都回到**原容器槽位**。
- **火/灵魂火**（生存模式）：不要求背包里有「火」物品，而是要求玩家身上（或附近容器内）有 **1 个打火石**；**每个火焰消耗打火石 1 点耐久**。附魔「经验修补」的打火石会保留最后 1 点耐久不消耗，并自动换用下一个打火石。
- **水/岩浆**（生存模式）：不消耗物品。背包中满足服务器配置的桶数（默认 **2 桶水** / **2 桶岩浆**）即可无限放置对应流体，桶本身不会被消耗。
- **破坏**：按工具正常掉落与损耗；单把工具不会用到剩余耐久低于 **4**，会自动换用背包中其他可用工具。
- 若任务只完成一部分（例如部分方块无法放置/破坏），服务器会按未完成数量**退还相应按块/按面积费用**，并退还未使用的放置材料。固定的「每次操作费」（若服务器启用）在已开始执行后通常不退。

## 形状一览

单方块、直线、墙、地板、立方体、对角线、对角墙、斜坡地板、圆、圆柱、球体、棱锥、圆锥。

## 没有客户端时

可使用服务器公开命令（需权限 `maxfastbuild.use`）。输入 `/mfb` 或 `/mfb help` 查看中文帮助。

```text
/mfb help
/mfb mode line
/mfb pos1
/mfb pos2
/mfb hollow false
/mfb apply
/mfb status
/mfb cancel
```

`apply` 与客户端一致：主手方块=放置/替换，主手镐斧等=破坏，空手拒绝（材料取自主手方块，不必再 `/mfb material`）。

## 用 Litematica 批量粘贴

客户端 Mod 与 **Litematica** 同时安装时，可以整份粘贴当前激活的投影，作为**一次**建造任务提交（服务器仍逐方块校验并收取材料/费用）。

1. 打开 Litematica 并在世界上放置一个 **SchematicPlacement**。
2. 将 MaxFastBuild 的「**粘贴当前 Litematica 投影**」键绑定到按键（默认未绑定，可在「选项 → 控制 → MaxFastBuild」设置）。
3. 按下该键，等待服务器校验完成。

注意事项：

- 方块实体（箱子、告示牌、讲台等）会**保留内容/文本**：粘贴容器时按**每种物品精确扣除**（容器本体 1 个普通方块物品 + 其存储内容里的每种物品），来源可为背包或附近容器。
- 可选「**即时粘贴**」：绑定「**切换即时粘贴**」键（默认未绑定），按下开启该模式（HUD 有提示）后再粘贴。即时粘贴按服务器 `instant-paste.multiplier`（默认 2 倍）收费并**立即执行**，无需排队；单次受 `instant-paste.max-blocks` 上限约束（默认 5000 格）。材料与工具耐久仍照常要求。
- 单次粘贴受服务器 `execution.max-region-blocks` 上限约束（默认 100000 格），超出请拆分更小的原理图。
- 与普通放置一样，生存模式会按**每种方块**从背包扣除材料，并做世界保护、工具耐久与经济校验。
- 未安装 Litematica 时该键无效；创意模式也走同一套校验（若服务器开启经济/材料则同样适用）。

## 常见问题

- **菜单打不开**：检查按键冲突；确认已安装客户端 Mod 并进入正确版本服务器。
- **无法选点**：确认已选模式，且主手是方块或工具。
- **提示材料不足**：背包（及开启容器取料时脚边 5 格内的箱子/木桶/潜影盒）中同种方块数量需不少于将要放置的格数；火需要打火石，水/岩浆需要对应桶。
- **提示扣款失败**：余额不足或服务器经济未就绪。
- **建造不完整还有退款提示**：属于正常结算，未成功变更的部分会退费/退材料。
