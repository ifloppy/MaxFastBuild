# MaxFastBuild 用户手册

![MaxFastBuild 图标](assets/maxfastbuild-icon.svg)

面向玩家的使用说明。服务端配置、权限与运维请另见管理员文档。

## 需要什么

- Minecraft Java 版 **26.2**
- **Fabric Loader** 与 **Fabric API**（与 26.2 匹配的版本）
- 服务器已安装并启用 **MaxFastBuild**（玩家侧只需客户端 Mod）

## 安装客户端

将客户端 jar 与 Fabric API 放入同一游戏实例的 `mods` 目录，启动游戏后加入支持本模组的服务器。

## 径向菜单

1. **按住**快捷键（默认 **左 Alt**，可在「选项 → 控制 → MaxFastBuild」改绑）打开菜单；**松开即关闭**。
2. 鼠标移到扇区高亮，**松开键**或**左键点击**选中模式。
3. 菜单背景透明，可看到身后世界。

## 放置与破坏

| 主手 | 行为 |
|------|------|
| 可放置的方块 | **放置**模式 |
| 镐 / 斧 / 铲 / 锄 / 剑 / 剪刀 | **破坏**模式（须能有效破坏目标；例如黑曜石需要合适镐） |
| 空手、弓、以及其他物品 | **无模式** |

### 选区操作

1. 从径向菜单选择形状（直线、墙、立方体等）。
2. **右键**确认第一个点，再 **右键**确认第二个点并提交。
3. **左键**取消当前选区。
4. 准星可对空气选点（浮空角点）；打到方块时，放置使用原版规则（可替换块用该格，否则相邻面）。
5. **Shift + 滚轮**调节视线延伸 **1～64** 格；普通滚轮仍切换物品栏。
6. 半透明预览只显示形状**外壳**与外框，避免大体积选区挡住视线。

### 费用与材料（由服务器决定）

- **放置**：生存模式下会从背包扣除对应方块；若服务器开启经济，会按规则扣费。材料或余额不足时会拒绝任务并提示。
- **破坏**：按工具正常掉落与损耗；单把工具不会用到剩余耐久低于 **4**，会自动换用背包中其他可用工具。
- 若任务只完成一部分（例如部分方块无法放置/破坏），服务器会按未完成数量**退还相应按块/按面积费用**，并退还未使用的放置材料。固定的「每次操作费」（若服务器启用）在已开始执行后通常不退。

## 形状一览

单方块、直线、墙、地板、立方体、对角线、对角墙、斜坡地板、圆、圆柱、球体、棱锥、圆锥。

## 没有客户端时

可使用服务器公开命令（需权限 `maxfastbuild.use`）：

```text
/mfb mode line
/mfb pos1
/mfb pos2
/mfb material minecraft:stone
/mfb hollow false
/mfb apply
/mfb status
/mfb cancel
```

## 常见问题

- **菜单打不开**：检查按键冲突；确认已安装客户端 Mod 并进入正确版本服务器。
- **无法选点**：确认已选模式，且主手是方块或工具。
- **提示材料不足**：背包中同种方块数量需不少于将要放置的格数。
- **提示扣款失败**：余额不足或服务器经济未就绪。
- **建造不完整还有退款提示**：属于正常结算，未成功变更的部分会退费/退材料。
